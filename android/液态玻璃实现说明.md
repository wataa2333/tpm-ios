# 液态玻璃试验分支

分支：`codex/android-liquid-glass`。基于删除月度密钥并开放人员工单统计的版本。

## 使用

我的 → 其他 → 开发者（原有开发者验证）→ 液态玻璃 → 启用液态玻璃。默认关闭，即时生效，重启保留。与人员工单统计的开放状态无关。

## 渲染方案

使用 Kyant0/AndroidLiquidGlass 的 Backdrop 1.0.0（固定版本）。选择该 Android 版本，是为了将工具链升级范围控制在 AGP 8.13.0、Gradle 8.13、Kotlin 2.2.21、Compose BOM 2025.11.00、compileSdk 36、JDK 21；安装最低版本仍为 Android 10，targetSdk 保持 35。后续升级 Backdrop 时须一并核对 Kotlin、Compose 和 SDK 要求。

- 顶栏使用作者官方 progressive-blur 示例的 alpha 遮罩方案，12dp GPU 模糊与主题染色渐变淡出。它是固定模糊半径的渐隐，不宣称是连续变化半径的精确渐进模糊。
- 所有主页面与二级页面的滚动内容占满视口，绘制到顶栏和底栏后面。首项随标题折叠调整顶部滚动留白，末项保留实测底栏高度与原有按钮空间。文字和图标在模糊层上单独绘制。
- 悬浮底栏及新建报修按钮使用同一份实际页面采样，加上 Backdrop blur / lens / highlight。批量选择时保留原批处理工具栏。
- 页面内的主按钮和 SoftButton 使用独立主题材质 CanvasBackdrop，避免把读取页面采样的控件再次录入同一采样层。它们不采样身后的工单正文。保持原有 onClick、enabled、按钮语义与 Material 涟漪，增加轻量按压缩放。
- 返回、刷新、多选、编辑、删除、清空等图标使用统一玻璃按钮。所有二级页面通过 GlassScaffold 采样各自滚动内容；列表筛选区在玻璃模式下进入列表滚动范围。批处理进度页也使用该框架。
- 表单、工单正文和统计表保持原有实色面板。开关与滑块使用玻璃底托，保留 Material 原生拖动、焦点与无障碍行为。主按钮、次按钮、描边按钮、筛选标签、菜单项、底部操作栏及应用内弹窗统一适配。弹窗与底部选择器使用独立主题材质，清空父页面的采样与滚动留白，避免跨窗口采样和重复留白。

## 兼容与关闭

Android 13+ 且硬件加速：模糊、镜头折射和官方 alpha-mask shader。Android 12：RenderEffect 模糊与隔离的渐变遮罩，不创建 RuntimeShader。Android 10/11 或软件绘制：半透明主题材质，不分配页面采样图层。关闭开关：恢复原有顶栏、实色导航栏、FAB 和 Material 按钮，不创建页面采样图层。

## 验收重点

检查浅色/深色、安卓 10/12/13+、连续滚动、横竖屏和大字体；顶栏图标可点击，待办角标保留，列表首尾不被永久遮挡，批量处理切换无布局错误；开关与账号/厂区切换互不干扰。正式发布前应在目标真机测量滚动丢帧与 GPU 开销。

## 页面与控件覆盖检查

| 页面组 | 统一入口 / 核对内容 |
| --- | --- |
| 主页、我的待办、工作台、我的 | GlassMainFrame；实时模糊顶栏、玻璃底栏、待办角标、新建按钮 |
| 工单列表、资产、库存、ERP 列表、保养/精度工单池 | OrderListScreen / PagedScreen → GlassScaffold；搜索、状态、日期筛选在玻璃模式下随列表滚动 |
| 报修详情、ERP 详情、处理流程 | GlassScaffold；正文滚动到栏后，任务与报修操作栏独立叠放 |
| 新建/编辑报修、维修完成、ERP 表单 | 共用 FormPage → GlassScaffold；保存、提交、草稿、照片按钮与选人/选物料弹层 |
| 任务处理、批处理进度 | GlassScaffold；暂停、继续、停止、完成、失败提示与原生圆形进度 |
| 人员工单统计、人员工单明细、趋势图 | GlassScaffold；日期/人员筛选、横竖屏分栏、原生圆形进度与百分比 |
| 精度统计与逐项数据 | GlassScaffold；筛选标签、统计数据和读取进度 |
| 草稿箱、卡片自定义、独立查询账号、开发者 | GlassScaffold；滚动安全留白、按钮和开关 |
| 登录、账号切换、历史更新日志、日期与通用消息弹窗 | 共用按钮/图标/弹窗材质；登录读取和历史日志使用原生圆形加载 |

加载动画统一使用 Material 3 CircularProgressIndicator。顶栏横条、SpinKit、自定义点点/波形/呼吸等绘制和样式选择器已移除；骨架卡片保留静态占位，不再扫光。可计量任务使用原生圆形确定进度并保留百分比和数量。关闭液态玻璃开关只恢复普通材质，加载指示器仍为原生圆形。

本地调试构建：`gradlew :app:assembleDebug`。中文 Windows 路径需要将项目移到纯英文路径，或添加本机参数 `-Pandroid.overridePathCheck=true`。这不是业务配置，不随仓库写入机器路径。
