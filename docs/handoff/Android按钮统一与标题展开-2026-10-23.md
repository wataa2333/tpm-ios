# Android 按钮统一与标题展开

用户截图反馈资产报修按钮样式与其他控件不统一、我的页面标题下拉无法展开，要求0.78版本。沿用实际Android版本序列更新为1.78.0/code78，iOS保持0.7.24/build30，不自动推送或编译。

## 修改

- Components.kt新增共享AssetReportButton，复用现有SoftButton/实心柔和背景与正文色，移除描边和独立紫色文字。详情、工单查询和资产台账展开卡片三个入口统一使用；保持独占整行、最小48dp高度，长文字可换行。详情仍在退单/完成任务下方，不改资产带入或业务权限。
- Chrome.kt的CollapsingBarState此前仅在onPostScroll用未消费下拉距离展开；列表弹性回弹会先消费该距离，导致标题收起后无法恢复。改成onPreScroll双向优先消耗标题所需距离，达到边界后将剩余手势留给列表/刷新/回弹。
- CollapsingTopBar支持直接纵向拖动及松手吸附。按钮点击仍由子控件处理，超过纵向触摸阈值才开始拖动。拖动方向与列表下拉一致。
- 拖动、自动展开和吸附通过motionGeneration隔离，新手势到来后旧动画不再覆盖位置。四个主Tab共用该标题组件。
- 新增两项CollapsingBarState回归用例：子列表消耗全部剩余距离时标题仍可先展开；直接拖动边界及只消费实际标题距离。未运行单测。
- 新增格式完整的android/releases/1.78.0-notes.txt，保留历史日志。
