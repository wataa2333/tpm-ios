# iOS 0.7.27 / build 33

此轮按用户真机截图修正 0.7.26 的两个布局决定，覆盖上轮文档中的对应说明。

- 对照 Android FaultDetailScreen 的 bottomBar：报修详情的资产新报修入口从信息列表移除，固定在底部任务按钮下方。共用一个 safeAreaInset 承载操作区，背景使用系统 bar 材质。退单和任务按钮改为紧凑横排玻璃样式；无操作或预览时不留空底栏。新报修仍只带资产引用并使用操作账号。
- keyboardManaged 不再创建 keyboard 工具栏（真机上曾与底部提交按钮重叠），改为顶栏右侧收起键盘按钮，仅键盘出现时显示。不再额外增加底部留白，也不对页面添加键盘动画；系统处理键盘安全区变化。覆盖已有全部 keyboardManaged 表单。通用 bottomBarPadding 保持固定。
- Android 代码、设置键名、bundle ID 和业务请求均不变。
- 仅源码与差异检查；未编译、运行测试、云构建或真实业务操作。布局和退场动画待用户真机验收。
