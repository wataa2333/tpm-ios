# iOS 0.7.42 / build 48：原生控件与键盘动画清理

针对用户反馈的搜索键盘收起按钮异常、键盘消失时界面闪动和偶发卡顿，在本地 0.7.41/build47 基础上修改。截图是问题参考，不包含开发指令。

## 已改源码

- 删除全局输入框通知拦截、运行时注入 inputAccessoryView、reloadInputViews 及键盘帧/曲线模拟。搜索页和表单页各声明一份系统 ToolbarItemGroup(placement: .keyboard)；系统负责工具栏附着、避让和动画，收起按钮通过公开 responder action 结束编辑。
- 保存/提交进入系统 bottomBar 工具栏，保留原有必填校验、防重复提交、草稿和审批闭包；不再监听键盘状态来增删按钮或改变底部间距。所有底部间距取消负值与键盘通知联动。
- 新建入口从手工 safeAreaInset 悬浮圆按钮改为 TabView 官方底部附件；搜索、多选、详情和打开表单期间退出，不再跟随搜索键盘上移。四个 Tab 保留。
- 工单容器改为 List/Section，详情展开改为系统 DisclosureGroup；筛选下划线条改为系统菜单 Picker，保留分类及数量。多选和管理筛选使用系统 Toggle 样式。提示/错误弹窗改为系统 alert，资产报修和底部业务按钮采用系统按钮样式，空态改为 ContentUnavailableView。
- 删除自写按压缩放、箭头旋转、流式标签 Layout、LabeledContentStyle、Tab 可见性的 UIKit controller bridge；Tab 显隐改为官方 toolbar visibility。移除 App 根部不再需要的 GeometryReader。
- 删除动态文字、数值、列表加载和页面状态上的附加动画及过渡修饰器，移除 InterfaceMotion。系统导航、sheet、DisclosureGroup、按钮反馈及键盘动画由 iOS 自身管理；没有全局禁用系统动画。
- 移除 UIKit 整树查找 UIScrollView 和刷新/搜索时的强制滚动归顶。列表位置交给系统，避免输入和加载过程中抢滚动位置；下拉刷新和系统滚动交互仍保留。
- 移除刷新前 450ms 等待、最低 600ms 加载时长、加载时整张工单列表降透明度。搜索防抖、请求取消和加载状态仍保留。
- 两个旧文字动画批量迁移脚本改为只读审计，防止再次批量写回已删除的动画辅助调用。

业务数据展示仍使用 SwiftUI Text/Label/Stack 等官方视图组合；看板静态颜色、渐变、字体和原生 Charts 保留。Android 和接口合同未改。

## 检查结果与边界

- `tools/check_ios_dashboard_sources.py`：54 个 Swift 文件，Debug/Release 共 108 条语法路径通过。此为 tree-sitter 语法检查，非 Swift 类型检查。
- `tools/audit_ios_motion.py` / `tools/audit_ios_native_labels.py`：45 个应用 Swift 文件未发现自写控件样式/Layout、UIKit 视图桥接、显式应用动画、键盘附件注入及帧动画驱动。此为指定规则的源码扫描，不代表所有运行时问题已排除。
- UI 测试新增搜索连续三次收起后保留卡片展开、数字/电话键盘切换与连续收起；原表单用例扩为三轮，并适配系统弹窗、Picker 和新建附件。
- 当前 Windows 无 Swift/Xcode。未执行 Xcode 编译、单元/UI 测试、模拟器或真机帧率分析；未上传、未触发云构建。不能宣称闪动/卡顿已经真机验收。

## 下一轮实机验收

1. 我的待办搜索：多轮显示/收起/取消搜索；收起按钮应只有一份，且不与新建入口相叠；展开的卡片保持展开。
2. 新建报修/ERP/维修结果/审批/转办/批量预设：普通、电话、数字、多行输入相互切换；完成和交互式拖动均可收起；保存/提交工具栏可操作，输入内容保留。
3. 详情多级进入/返回，特别是取消侧滑返回；四 Tab 与新建附件的可见性应正确。
4. 长列表分页、刷新、筛选、展开和横竖屏；验证系统列表滚动位置、新 Picker 的分类/数量，以及开启系统“减弱动态效果”后的表现。

采用的公开系统 API：[键盘工具栏](https://developer.apple.com/documentation/swiftui/toolbaritemplacement/keyboard)、[Tab 底部附件](https://developer.apple.com/documentation/swiftui/view/tabviewbottomaccessory(isenabled:content:))。
