# iOS 0.7.26 / build 32

- 基于 GitHub main a81bced 同步后的最新代码修改，Android 不变。
- 资产报修按钮使用原生 glass 样式，报修详情中的入口移动至报修资产下方，移除底部重复入口，底部只保留业务任务按钮。表单仍使用当前操作账号，仅传递资产引用。
- 精密度看板按操作账号、查询账号及厂区隔离保存上次展示快照。进入优先恢复并提示非最新，不自动联网刷新；首次无缓存仍读取。仅缓存看板显示字段，不保存凭据或操作载荷，排除系统备份并使用文件保护。旧数据下不自动逐台查询检测上传人员；点击设备详情沿用实时读取。
- keyboardManaged 改用系统 keyboard 工具栏；所有 bottomBarPadding 使用固定间距，移除键盘通知驱动的第二套页面 inset / padding 动画。覆盖报修、ERP、任务、批量及查询账号表单。
- 开发者读取档位关闭实验开关后不再清空所选页大小和并发。沿用既有 AppStorage 键与 bundle identifier；未发现启动或更新时清空全部偏好的逻辑。应用容器被卸载或更换包名清除时，普通偏好不在本轮承诺恢复范围内。
- 独立查询设置明确当前已生效账号；移除未验证账号的硬编码预填，输入或选择账号后仍需“验证并使用”，成功后展示提示。隐藏该详情页底栏与全局加号。业务写操作仍使用操作账号。
- 仅源码及差异检查；未 Xcode 编译、运行测试、Codemagic 构建或真实业务操作。键盘实际退场和液态玻璃效果待用户真机验收。
