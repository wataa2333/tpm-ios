# 液态玻璃试验分支

分支：`codex/android-liquid-glass`。基于删除月度密钥并开放人员工单统计的版本。

## 使用

我的 → 其他 → 开发者（原有开发者验证）→ 液态玻璃 → 启用液态玻璃。默认关闭，即时生效，重启保留。与人员工单统计的开放状态无关。

## 渲染方案

使用 Kyant0/AndroidLiquidGlass 的 Backdrop 1.0.0（固定版本）。选择该 Android 版本，是为了将工具链升级范围控制在 AGP 8.13.0、Gradle 8.13、Kotlin 2.2.21、Compose BOM 2025.11.00、compileSdk 36、JDK 21；安装最低版本仍为 Android 10，targetSdk 保持 35。后续升级 Backdrop 时须一并核对 Kotlin、Compose 和 SDK 要求。

- 顶栏使用作者官方 progressive-blur 示例的 alpha 遮罩方案，模糊档位与控件同步，主题染色渐变淡出。它是固定模糊半径的渐隐，不宣称是连续变化半径的精确渐进模糊。
- 所有主页面与二级页面的滚动内容占满视口，绘制到顶栏和底栏后面。首项随标题折叠调整顶部滚动留白，末项保留实测底栏高度与原有按钮空间。文字和图标在模糊层上单独绘制。
- 悬浮底栏、新建报修、顶栏按钮及底部操作按钮使用实际页面采样，加上 Backdrop blur / lens / highlight。批量选择时保留原批处理工具栏。
- 位于正文采样层内部的按钮使用独立主题材质 CanvasBackdrop，避免采样层递归引用；它们不采样身后的工单正文。位于顶栏、底栏及悬浮层的主按钮和 SoftButton 继承实际页面采样。保留 onClick、enabled、按钮语义与 Material 涟漪，补充触摸光泽与方向形变。
- 返回、刷新、多选、编辑、删除、清空等图标使用统一玻璃按钮。所有二级页面通过 GlassScaffold 采样各自滚动内容；列表筛选区在玻璃模式下进入列表滚动范围。批处理进度页也使用该框架。
- 表单、工单正文和统计表保持原有实色面板。开关与滑块使用玻璃底托，保留 Material 原生拖动、焦点与无障碍行为。主按钮、次按钮、描边按钮、筛选标签、菜单项、底部操作栏及应用内弹窗统一适配。弹窗与底部选择器使用独立主题材质，清空父页面的采样与滚动留白，避免跨窗口采样和重复留白。

## 兼容与关闭

Android 13+ 且硬件加速：模糊、镜头折射和官方 alpha-mask shader。Android 12：RenderEffect 模糊与隔离的渐变遮罩，不创建 RuntimeShader。Android 10/11 或软件绘制：半透明主题材质，不分配页面采样图层。关闭开关：恢复原有顶栏、实色导航栏、FAB 和 Material 按钮，不创建页面采样图层。

## 验收重点

检查浅色/深色、安卓 10/12/13+、连续滚动、横竖屏和大字体；顶栏图标可点击，待办角标保留，列表首尾不被永久遮挡，批量处理切换无布局错误；开关与账号/厂区切换互不干扰。正式发布前应在目标真机测量滚动丢帧与 GPU 开销。

| 页面组 | 统一入口 / 核对内容 |
| --- | --- |
| 主页、我的待办、工作台、我的 | GlassMainFrame；实时模糊顶栏、玻璃底栏、待办角标、新建按钮 |
| 工单列表、资产、库存、ERP 列表、保养/精度工单池 | OrderListScreen / PagedScreen → GlassScaffold；搜索、状态、日期筛选在玻璃模式下随列表滚动 |
| 报修详情、ERP 详情、处理流程 | GlassScaffold；正文滚动到栏后，任务与报修操作栏独立叠放 |
| 新建/编辑报修、维修完成、ERP 表单 | 共用 FormPage → GlassScaffold；保存、提交、草稿、照片按钮与选人/选物料弹层 |
| 任务处理、批处理进度 | GlassScaffold；暂停、继续、停止、完成、失败提示与原生圆形进度 |
| 人员工单统计、人员工单明细、趋势图 | GlassScaffold；日期/人员筛选、横竖屏分栏，统计概览使用原生条形进度与百分比 |
| 精度统计与逐项数据 | GlassScaffold；筛选标签、统计数据和读取进度 |
| 草稿箱、独立查询账号、开发者 | GlassScaffold；滚动安全留白、按钮和开关 |
| 登录、账号切换、历史更新日志、日期与通用消息弹窗 | 共用按钮/图标/弹窗材质；登录读取和历史日志使用原生圆形加载 |

常规加载使用 Material 3 CircularProgressIndicator，人员工单统计页恢复 LinearProgressIndicator 条形进度。顶栏横条、SpinKit、自定义点点/波形/呼吸等绘制和样式选择器已移除；骨架卡片保留静态占位，不再扫光。可计量任务使用原生圆形确定进度并保留百分比和数量。关闭液态玻璃开关只恢复普通材质，加载指示器仍为原生圆形。

本地调试构建：`gradlew :app:assembleDebug`。中文 Windows 路径需要将项目移到纯英文路径，或添加本机参数 `-Pandroid.overridePathCheck=true`。这不是业务配置，不随仓库写入机器路径。

- 顶部分类切换保持同一个页面和列表容器，不再播放整块页面横滑；人员统计进度为条形，计数和状态为普通文字原位更新。

## 1.107.0 材质和自调选项

- 修正 GlassActionButton / GlassButton 强制使用独立材质的调用；新建报修、顶栏及底部操作按钮现在继承外部页面采样。正文内部与跨窗口弹层仍隔离采样，避免递归图层。
- 透明染色降为 28%（普通）/ 32%（主操作），恢复 Backdrop 单层 0.7dp 方向高光、柔和阴影和 10dp / 20dp 的镜头折射，并启用深度效果。模糊强度单独控制，不再随降低模糊一起削弱折射。
- 按钮增加触点光泽、4dp 按压膨胀、方向拉伸与有界跟随；松手及父列表接管手势时回位。变换只作用于绘制层，不改变布局和命中区域，不消费父列表滚动事件。
- 底栏选中胶囊使用玻璃材质，横拖时膨胀并跟随，松手吸附。关闭弹性动效后保留导航手势。
- 开发者 → 液态玻璃：模糊提供关闭 / 低 / 中 / 高（0 / 2 / 6 / 12dp）；高光、折射、色散、阴影、弹性分别开关。默认低模糊，高光、折射和弹性开启，色散和阴影关闭。设置立即生效，写入 ui_options 并在重启时恢复；恢复默认只影响这组效果选项。
- 所有调节直接放在正式 App 的开发者页面，通过共享材质作用于实际业务控件。移除独立演示 Activity 和预览按钮，不提供演示界面。
- 折射、深度和色散需要 Android 13+；Android 12 保留模糊与高光；旧系统按原策略降级。关闭模糊仍可独立保留其他效果。
- 玻璃主按钮及选中选项使用适合透明底的文字颜色，避免沿用不透明主色按钮的白字造成低对比度。
- 已通过 Debug 构建及 11 项玻璃外观、设置持久化、交互与降级单元测试；新增选项与正文采样边界不涉及统计查询或工单业务逻辑。

- 顶栏左右增加 16dp 安全留白，操作按钮之间增加 8dp 间隔；大标题顶栏同样保留右侧间距。
- 轻量默认：正文内的平滑主题材质跳过无收益的模糊处理，悬浮控件共享一份页面图层；色散和额外模糊阴影默认关闭，触点光泽只在交互期间绘制。未进行目标真机帧率测量，不声称具体性能提升比例。

## 1.108.0 反馈修正

- 修正列表 NewButton 放在 GlassScaffold 作用域之外的问题，改用共享采样的固定悬浮层；保持批量选择时原有显示/隐藏行为，不随底栏高度跳动。
- 底部操作区改为无描边、无圆角外壳的渐变模糊背景，并覆盖系统手势区域；内部按钮各保留一层玻璃。删除 GlassBottomSurface 的额外圆角折射底托和批量栏的实色底板。
- 按压膨胀按每个轴的实际像素计算，完整宽度的按钮不再按高度比例横向放大；拖动与膨胀总越界控制在预留的 8dp 内。展开动画结束后停止裁切其内容，保留收展过程中的必要裁切。
- 返回按钮与标题增加 12dp 间隔，右侧操作组与标题同样隔开；横向分类和选择方式使用原生滚动加局部边缘渐隐，避免硬切胶囊。
- 搜索框、分类/日期/等级胶囊、主题切换、文本操作、工作台查询、表单选择/输入及我的页入口统一使用共享玻璃适配；仍由 Material / Foundation 处理输入、点击、禁用和无障碍语义。
- GlassSwitch 保留原生拇指和交互，只给 52×32dp 的轨道绘制玻璃，移除覆盖整个触摸区域的多余圆形底托；滑块同样限制在轨道范围。
- 人员弹层使用稳定的窗口背景、增加标题上下留白，关闭/完成按钮走共享玻璃控件。玻璃模式下关闭滚动视口的实色渐隐遮罩，消除列表与固定搜索区之间的白带。
- 移除我的页和开发者页的加载预览；人员统计删除顶部重复进度，保留页内条形进度。精密度概览将覆盖率改成原生条形进度，首次请求只在页内显示一处加载；动态数据使用普通文字更新。
- 卡片标题与正文间隔统一 8dp；编号与时间按真实文字行高加 8dp 排列，移除固定大行槽。普通正文行高为 22sp，小字行高为 20sp；详情标签列扩到 112dp，避免联系电话标签只剩一个字换行。骨架布局同步。
- 升级到此版本时一次性重置模糊为低档、关闭色散，其他效果选择保留；此后用户自行调整仍会保存。
- 验证范围：正式 App Debug 构建，以及卡片字段布局、玻璃降级/外观/设置持久化和按压边界共 35 项单元测试。未新增或打开演示页面，未进行目标设备逐页视觉及帧率验收。
