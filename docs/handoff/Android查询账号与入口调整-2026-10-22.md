# Android 查询账号与入口调整

源码版本 1.75.0/code75。用户自行 Studio 编译，本轮未编译、运行测试、推送或执行真实工单操作。

- 我的 → 外观下新增其他分类，含开发者选项、独立查询账号；开发者密码验证保留，移除标题连点入口。
- 查询账号默认 C0382522。用户提供的默认密码仅存于忽略提交的 android/local.properties 的 tpm.defaultQueryPassword，由本机构建注入 BuildConfig。其他机器需要自行配置该属性或在 App 内填写密码，不把密码写入交接或源码。
- QueryAccounts 保留独立加密凭据与内存 token；只读路径白名单扩大到维修查询、资产/ERP查询、看板和数量读取。Session.readRequest/readPage 使用查询账号，正常 request/page 和上传保留登录账号。我的待办不切换查询身份。
- 维修详情使用查询身份读取展示；操作按钮绑定当前登录账号重新读取的单据，后续流程权限、表单、提交和上传仍用原登录会话。不可见或无操作权限显示提示，不能借用查询 token 操作。批量操作原有操作前权限核对继续保留。
- 查询账号变更清空列表及看板旧结果，异步结果校验 revision；查询失败不静默回退主账号。允许显式选择当前登录账号，并保存选择。
- 工作台改称看板；精密度入口不依赖开发者管理开关，右侧改箭头。维修人员看板开关仍保留。
- 搜索与等级筛选增加间距，待处理人员卡片使用强调色层次；维修趋势图移除调整按钮和滑条；统计表换轴使用 AnimatedContent 与 SizeTransform。

待真机检查：默认账号登录与厂区权限、账号切换、查询账号无权限提示、登录账号无操作权限提示、键盘下设置页滚动、强调色辨识度及表格换轴尺寸动画。未把源码审阅当作编译或设备通过。
