# 原生 iOS 单据工作台

第一版为 SwiftUI 原生界面骨架：工作台、搜索、详情、处理意见弹窗与本地模拟处理。使用系统 Tab、NavigationStack、List、Form 与工具栏，无自绘系统控件。数据为虚构示例，与原系统的字段或审批规则不构成对应承诺。关闭应用后模拟处理状态重置；意见暂不保存。

未连接服务器，未实现真实认证、附件或业务提交。目标 iOS 27。Windows 本地尚未编译、运行或验证外观；SwiftUI 源码不能替代运行截图。

## 免费构建与安装路线

1. 将本项目放入自己的私有 GitHub 仓库；不要上传原 APK 或提取资源。
2. 在 Actions 手动运行 Build iOS preview。使用账户内免费额度，费用预算保持为零；此工作流不自动触发。
3. 工作流要求 runner 所选 Xcode 提供 iOS 27 SDK，否则会明确失败，需根据 GitHub 当前可用镜像调整 runner 或 Xcode 选择。
4. 下载 TPM-unsigned 构建产物并解压，得到未签名 IPA。它不能直接安装。
5. 在自己的 Windows 电脑用 Sideloadly 和普通 Apple 账号本地签名安装，按提示启用开发者模式。Apple 登录与验证由用户在工具中完成，不上传密码到仓库或聊天。
6. 免费签名通常 7 天有效，需要刷新；iOS 27、两台设备及本应用的实际签名兼容性均待测试。

云端构建需要先有仓库和账号配置，目前未上传或运行。未签名包的生成方案也需要首次 macOS 构建验证。真实 iOS 截图需额外运行模拟器或由真机取得。
