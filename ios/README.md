# 原生 iOS 单据工作台 0.2

原生 SwiftUI 界面预览，目标 iOS 27。底部主页、工作台、故障报修、我的。

主页：待受理、维修工单池、保养工单池、精密度检查工单池。
工作台：资产台账搜索与详情、ERP 出库列表与明细、库存搜索与详情。
故障报修：四种状态、搜索、新建表单、设备选择、照片选择器、详情与处理意见。
图标：三角莲花的简约矢量构造，蓝青紫轻微渐变，由云端构建渲染为 PNG。

所有单据、人物、设备与库存数值均为虚构示例。尚未连接服务器；本地演示操作不影响真实工单、库存或 ERP。数据在重启后重置。照片不上传、不保存原图。真实状态、权限和字段需对照原包进一步核实。

构建：GitHub Actions 手动触发，使用 xcode-27 标准环境、XcodeGen 生成工程。一次构建产生未签名 IPA 和 iOS 模拟器截图，保留三天。批量截图通过 DEBUG 参数直接打开页面，不能替代端到端交互测试。私有仓库免费额度消耗与余额以 GitHub 账户为准，不配置付费服务。

安装：下载未签名 IPA 后，可尝试在 Windows 用 Sideloadly 与普通 Apple 账号本地签名。免费签名通常七天需要刷新，iOS 27 及两台手机的实际安装兼容性仍待验证。Apple 登录由用户在本地工具内完成。

仓库：https://github.com/wataa2333/tpm-ios
