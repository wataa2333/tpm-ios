# 动画时长与曲线规范（安卓端，2026-10-18）

所有动画的时长和曲线都从 `ui/Motion.kt` 取，页面里不再写自己的毫秒数。

## 时长（五档）

| 档位 | 毫秒 | 用在什么上 |
|---|---|---|
| Instant | 100 | 按压反馈、勾选、小图标转动 |
| Fast | 250 | 渐隐、让路收起、副标题和数字的小滑动 |
| Normal | 300 | 原地状态变化：胶囊/选项变色、标题切换、卡片收起 |
| Slow | 450 | 打开与出现：卡片展开、底栏升起、骨架融成卡片、详情淡入 |
| Page | 600 | 整页滑入滑出 |

## 曲线（从最线性到最不线性）

| 曲线 | 用在什么上 |
|---|---|
| Linear | 只用于没有起止的动作：刷新图标旋转、必须首尾相接的加载动画（波浪类） |
| Standard（慢-快-慢） | 在屏幕上开始也在屏幕上结束的变化，tween 的默认值 |
| Decelerate（先快后慢） | 到来的东西：页面滑入、底栏升起、卡片展开 |
| Accelerate（先慢后快） | 一去不回的东西 |

## 例外（有意保留）
- 加载动画自己的循环时长（1200~1800ms）、刷新图标一圈 900ms：它们是循环，不属于上面的档位。
- 弹簧（下拉回弹、勾选弹出）：用 spring，不用 tween。
- 延迟（delayMillis）保持原值。

## 补充（2026-10-18）
默认值已改为：瞬间 100 / 快 250 / 常规 300 / 慢 450 / 整页 600 毫秒；到来、离开、变化三种曲线默认都是“慢快慢”。数值与曲线可在开发者页（我的页标题连点 10 次）调整并保存。
