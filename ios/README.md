cd ios

python3 ios/check-native-ui.py

本版重点为报修、自修、ERP 多物料领料和实际流程节点。主页与我的提供厂区切换：读取账号授权厂区，调用原接口取得新令牌，成功后重建页面并刷新数据，丢弃旧厂区未完成的请求结果。外协维修及外协 ERP 申请暂不提供。保养、精密度检查维持演示范围。
