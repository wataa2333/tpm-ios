# Android 精密度接口最小验证 · 2026-10-22

用户最新范围：先验证安卓版登录会话能否返回精密度分析数据；其他详细功能、图表暂不做，用户自行用 Android Studio 编译。本次未编译、未打包、未推送，也未用 Android 登录令牌实测。

## 入口与行为

- 我的标题连续点击10次，进入开发者（沿用原密码验证），找到“精密度接口验证”，点击“验证精密度接口”。
- 复用 `LocalSession` 的当前账号、当前厂区、现有服务器 `tpm.forbetter.cn:8855` 和 Bearer 登录令牌。不读取或复制 Chrome 的凭据，不新增登录流程。
- 仅手动调用只读 POST `precise/getPreciseAnalysis`，请求结构与网页一致：`type=region`、空 `layerCode`、在用、正常/报警/故障、AA/A/B/C/D，及网页默认的 `inspectStates/faultStates/maintainStates`。
- `categoryIds=[]`，读取当前账号可见的分析项后，按 `asset.assetCategory.categoryCode=017` 且 `categoryName=017CNC加工中心` 过滤显示，不硬编码茶山的类别ID1849到其他厂区。
- 显示真实返回分组数、分析项数量、017CNC数量及最多3条设备编码/品牌/等级/分析日期样例。空响应明确提示不能确认可见目标设备；返回结构异常报错，不当作0条成功。
- 403显示账号无权限；其余错误显示失败原因。沿用 Session 的401退出登录逻辑。页面离开、账号或厂区改变时取消任务并清空结果，避免旧结果混用。不落盘业务响应。

## 网页已经验证的证据

Chrome 开启 CDP 后，`POST /rest/precise/getPreciseAnalysis` 返回200，结构为分组数组，每组包含 `preciseAnalysisList`，每项含 `analysisId/asset/analysisResult/analysisDate`。品牌位于 `asset.brand.brandName`。

网页无类别筛选749项，筛选茶山类别1849后747项。网页会话成功不代表 App 令牌必然有接口权限；两个客户端主机名也不同，因此本次探针保持 App 原服务器，等待用户实测结果。

目前未做统计图、覆盖率计算、每日新增历史记录统计或 iOS 接入。`analysisDate` 是当前分析结果日期，不可未经核实直接称为每日新增历史记录数。
