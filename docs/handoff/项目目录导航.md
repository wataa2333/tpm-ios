# 项目目录导航

## 工作目录

| 目录/文件 | 用途 |
| --- | --- |
| docs/handoff/ | 当前交接入口、状态、跨平台清单、目录导航 |
| android/ | Android Studio打开此目录；Gradle工程与Android说明文档 |
| android/app/src/main/java/com/personal/tpm/ | Android源码；data业务/协议、ui界面、update全量更新 |
| android/app/src/test/ | 离线单元测试，使用假数据 |
| android/app/src/main/assets/licenses/ | 开源动画许可证 |
| android/releases/ | 版本日志；现有1.58.0日志尚未涵盖最后几轮修改 |
| ios/TPM/ | iOS SwiftUI源码 |
| ios/TPMTests/、ios/TPMUITests/ | iOS自动化；具体以工程配置为准 |
| ios/project.yml | XcodeGen配置、iOS版本号来源 |
| tools/ | Android发布、授权工具、只读核对脚本；不批量运行，部分工具可能读取本地会话 |
| codemagic.yaml、.github/ | 云构建配置；整理文档不自动触发构建 |
| build/ | 本地日志和历史产物，不作为源码或新版本来源，不上传 |
| .private/ | 私密运行/凭据资料；不读取、不上传 |
| apk-analysis/、base.apk | 本地原客户端核对资料；不上传，不常规通读 |

## 既有文档位置

根目录CLAUDE.md保留工作边界；项目交接说明.md、下一个对话工作要求-2026-10-16.md、UI回归-2026-10-16.md主要是iOS历史。流程核对.md仍是业务契约依据，冲突时需核对当前请求而不是盲改。

Android专题继续留在android/：自动更新发布说明.md、管理看板数据口径-2026-10-21.md、UI反馈处理记录-2026-10-20.md、动画规范.md、界面层级.md。更新与批量处理验收记录-2026-10-20.md包含已废止增量方案，只保留历史，不照旧启用。

## 为什么没有搬动源码或清空build

现有Gradle/XcodeGen、脚本和历史链接使用这些路径。此次采用docs/handoff集中导航，保留源码/配置/旧文档路径；没有删除构建缓存、旧产物、私密资料或移动用户签名文件。旧记录不再作为新对话起点。

不打整目录压缩包交给其他工具，避免混入会话、授权密钥CSV、签名、原APK或业务快照。新对话访问同一工作目录即可；需要分享时只分享明确筛选过的源码和交接文档。
